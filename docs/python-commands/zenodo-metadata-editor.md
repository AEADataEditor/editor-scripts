# `zenodo-metadata-editor`

[Source](https://github.com/AEADataEditor/editor-scripts/blob/main/aea_editor_scripts/zenodo_metadata_editor.py)

![Linux](https://img.shields.io/badge/-Linux-success)
![macOS](https://img.shields.io/badge/-macOS-success)
![Windows](https://img.shields.io/badge/-Windows-success)

Edits Zenodo deposit metadata and adds related identifiers (e.g. linking a
journal article DOI to a data and code package). Supports the Zenodo sandbox and
production.

```
zenodo-metadata-editor --deposit-id ID --article-doi DOI --replpkg-doi DOI [--production] [--publish]
```
