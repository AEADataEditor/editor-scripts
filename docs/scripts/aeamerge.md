# `aeamerge`

[Source](https://github.com/AEADataEditor/editor-scripts/blob/main/aeamerge)

![Linux](https://img.shields.io/badge/-Linux-success)
![not macOS](https://img.shields.io/badge/-macOS-red)
![Not Windows](https://img.shields.io/badge/-Windows-red)

Merges the PDF of an external reviewer report into the AEA official report and
commits the merged PDF, ready to send to the author.

Requires `qpdf`. Linux only.
