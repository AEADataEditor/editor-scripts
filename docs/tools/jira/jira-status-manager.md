# `jira-status-manager`

[Source](https://github.com/AEADataEditor/editor-scripts/blob/main/aea_editor_scripts/jira_status_manager.py)

![Linux](https://img.shields.io/badge/-Linux-success)
![macOS](https://img.shields.io/badge/-macOS-success)
![Windows](https://img.shields.io/badge/-Windows-success)

Queries and updates Jira issue status and the MC Recommendation field. Lists
available transitions and executes them by keyword or number.

```
jira-status-manager aearep-NNNN [action] [recommendation]
```

Requires `JIRA_USERNAME` and `JIRA_API_KEY`.
